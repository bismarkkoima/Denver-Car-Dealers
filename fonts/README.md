Self-hosted copy of [Mona Sans](https://fonts.google.com/specimen/Mona+Sans) from Google Fonts,
under the [SIL Open Font License 1.1](https://openfontlicense.org). It's a variable font: the site
uses its expanded width (125%) for headlines and labels, close to Cadillac's wide look, and normal
width for reading text. `fonts.css` declares it.
